# Instagram Insights Kit（プレビュー版）

Instagramの数字をGoogleスプレッドシートへ集め、AIと分析するための収集プログラムとセットアップ支援スキルです。

対象は、本人が管理するInstagramプロアカウントとFacebookページ、macOS、Python 3.10以上、Codexです。Windows・サービスアカウント認証は未対応です。

## 始め方

GitHubの「Code → Download ZIP」で取得し、展開してください。以後の手順は [START-HERE.md](START-HERE.md) を参照してください。GitHubアカウントはZIP取得には不要です。

1. スキルと依存ライブラリをインストール。
2. AIの案内に沿ってInstagram・Meta・Googleを設定。ログインと同意は本人が行います。
3. 初回収集、対象アカウント、シートへの書込・読み戻しを確認。
4. 希望する場合だけMacで1日4回の収集を登録。
5. 集まった表をAIで分析。分析依頼の自動実行は含みません。

## 収集と集計の意味

- 投稿・リール：取得時点の累計指標。取得できない指標は空欄で、0ではありません。
- 月次表：投稿月ごとの取得時点累計です。月間の活動実績や月間ユニークリーチではありません。
- アカウント：フォロワー数は収集時点の値、増減は前回保存日との比較。リーチ等は前UTC日を指定して取得します。日本時間の売上日報とは期間が異なります。
- ストーリーズ：取得できた公開中のものだけ保存。導入前や未収集のまま消えたものは復元できず、最終確定値を保証しません。
- 指標の提供状況・権限・履歴上限はMetaの条件に依存します。PARTIALは一部指標欠損です。

## 安全上の前提

専用の新規スプレッドシートを作り、アカウントID・シートID・タブIDを記録します。記録と一致しない既存表は更新できません。自動生成タブはプログラム専用です。手入力・数式は別タブに置いてください。手作業のグラフは削除しません。履歴は `data/<アカウントID>/` ごとに分離し、同時実行はロックで防ぎます。

トークン、認証JSON、実データは公開しません。AIチャット・画面録画・Issueにも貼らないでください。取得データを外部AIに渡す場合は、そのサービスへの送信範囲を本人が確認してください。

Google認証は `drive.file` のみを要求します。全スプレッドシートの権限は要求しません。旧版の広い権限のトークンは拒否するため、Google側で旧連携の権限を解除してから新しいキットで再認証してください。ファイルを消すだけではGoogle側の権限解除になりません。

認証・履歴ファイルは所有者だけが読書きできる権限、データフォルダーは所有者だけがアクセスできる権限で保存します。Meta APIのHTTPリダイレクトは拒否します。これは端末の管理者や同じOSユーザーで動く他アプリからの隔離・暗号化ではありません。

投稿本文・プロフィール名には個人情報が含まれ得ます。このキットは個人情報を自動除去しません。Metaトークンの自動更新・失敗通知・サーバー常時稼働は含みません。Macがログインして稼働中であることが前提です。アプリ審査や利用条件を回避するものではありません。
