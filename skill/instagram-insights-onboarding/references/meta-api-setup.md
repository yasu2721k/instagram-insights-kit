# Meta API接続

単一事業者のローカル収集では、本人が管理するMetaアプリと本人の資産を使う。複数顧客へ共通アプリを配布する製品提供は別モードであり、必要なApp Reviewとデータ取扱い整備を完了するまで顧客資産へ接続しない。

## セットアップ

1. Meta for Developersでアプリを作成する。
2. 現行のInstagram API製品を追加し、Facebookログインを使う構成ではページとInstagram資産を列挙・参照できる最小権限を選ぶ。
3. Graph API Explorerまたは公式OAuthフローで、対象ユーザーが対象FacebookページとInstagramを選択して許可する。
4. ページ一覧から対象ページを特定し、接続されたInstagramプロアカウントIDを取得する。
5. 対象アカウント名と最新投稿が一致することを確認し、インサイト参照をテストする。
6. 短期トークンを長期トークンへ交換できる構成では交換し、有効期限と更新ジョブを記録する。

権限名やAPIバージョンは実装時点のMeta公式ドキュメントで確認する。投稿公開権限やメッセージ権限は、データ収集だけなら追加しない。

## 秘密情報

- App Secretとアクセストークンは本人の端末上で入力・保存する。
- チャット、スクリーンショット、状態JSON、Gitへ貼らない。
- 診断出力は「存在する／期限／伏せた識別」まで。
- 漏えいが疑われる場合は検証より先に無効化・再発行する。

## 合格条件

- InstagramビジネスアカウントIDが対象プロフィールと一致
- 最新投稿のID・日時・パーマリンクが取得できる
- 少なくともアカウントまたはメディアのインサイト1項目が取得できる
- APIエラーを成功扱いして空データを書き込んでいない
